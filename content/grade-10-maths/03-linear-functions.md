# Linear Functions

A linear function has the form y = mx + c. Its graph is a straight line. The gradient m tells you how steep the line is: rise divided by run. The y-intercept c is where the line crosses the y-axis.

To find the gradient between two points (x₁, y₁) and (x₂, y₂), use m = (y₂ − y₁) / (x₂ − x₁).

Example: The line through (1, 3) and (3, 7) has gradient m = (7 − 3) / (3 − 1) = 2. Substituting (1, 3) into y = 2x + c gives c = 1, so the equation is y = 2x + 1.

Note: Parallel lines have equal gradients. Perpendicular lines have gradients whose product is −1.
