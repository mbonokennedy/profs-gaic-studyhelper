# The Discriminant

The discriminant of ax² + bx + c = 0 is Δ = b² − 4ac. It tells you the nature of the roots without solving the equation.

If Δ > 0 there are two different real roots. If Δ = 0 there is one repeated real root. If Δ < 0 there are no real roots. If Δ is a perfect square (and a, b, c are rational) the roots are rational.

Example: For 2x² + 3x − 2 = 0, Δ = 3² − 4(2)(−2) = 9 + 16 = 25. Because 25 > 0 and is a perfect square, there are two rational roots (x = ½ and x = −2).

Note: The discriminant is the part under the square root in the quadratic formula. That is why a negative discriminant means no real solutions.
